HearthLedger: a household budget site with a dashboard of income vs spending, full transaction management, per-category budgets, savings goals, six-month reports and CSV export — all offline in the browser.

## Run it

```sh
node main.ts
```

Serve the site locally with `node serve.ts`, then open http://localhost:8080. Views: dashboard, transactions, budgets, savings goals, reports, settings — everything runs offline from app/.
